Return one joint JSON annotation in the supplied schema. No tools, commentary,

REFERENTS AND QUOTATIONS
Group referring expressions by actual identity. Use a lowercase local key (n0,
m0, e0, v0, c0, etc.) once per record, globally unique in this response. A referent
identity is either a prior catalog entity key (N0, N1, ...) or a new description
{label, concept, kind}. Prior uppercase keys and current lowercase keys are distinct.
Do not redeclare an old entity as new when its identity is already established.
Unresolved expressions may introduce an unresolved referent; mark uncertainty.
Every referent must have an actual current mention. Do not make auxiliaries,
conjunctions or arbitrary neighboring words into participants. A pronoun mention
quotes the pronoun; a descriptive mention quotes the referring noun phrase.
Use explicit/inferred/unresolved reference_status. The compiler determines first
mentions, permanent identifiers and reproducible textual antecedent pointers.

Every quote is {quote, occurrence}. Copy contiguous source WORDS exactly, retaining
case/contractions and separating them by spaces; omit punctuation between words.
occurrence is ONE-BASED in the CURRENT UNIT for mention spans and event triggers,
and in the ENTIRE AVAILABLE PREFIX for evidence/uncertainty. Prefer sufficiently
distinctive evidence quotes to avoid counting many repeated words. New evidence
must reach the current unit; event evidence must contain its trigger. Do not output
token indices. Evidence may include prior context but never unseen later text.

MEANING
Include text-supported events and states, including adjectival, nominal and
relational predication where semantically appropriate. Use a lowercase predicate
lemma or short underscore-separated concept; retain a sense_id only if known.
Do not split every auxiliary or copula into another event. Negation belongs to
the proposition it negates. A hypothetical or reported event remains annotatable
without becoming a claim that it happened. Do not enumerate unexpressed implications.
Use general roles by meaning (agent, experiencer, patient, theme, content, etc.),
not simply grammatical subject/object. Frame roles are optional; ARG0 is not
universally agent and ARG1 is not universally patient.

Arguments target a current mention key when grounded by a current expression;
otherwise a prior mention/entity, current referent, event or literal key. Forward
event references in this response are legal. Do not invent a participant mention
to satisfy an event role. Literal values represent names, text, quantities, dates,
times, numbers or booleans; they are values, not additional discourse entities.

Examples of representation decisions (not source facts):
- "Tom loved the novel JT had written called Sarah": one novel referent, with
  love and write predicates and a name predication/value for Sarah. Sarah is the
  novel's name, not a second novel. A mention of Sarah refers to that same novel.
- "Scientists think this is not the only universe we inhabit": preserve the
  reported/believed content and negated uniqueness. Do not invent an identified
  second universe from the implication of "not the only". The inhabit participant
  denoted by "we" must not become "scientists" unless the prefix supports that identity.
- "Mary said John wanted to leave": the leave event can be inside a desired
  context nested under reported content. Do not collapse these to one status.
- "The stranger was Alice": if two previously distinct identities become equated
  here, record an identity_link with current evidence; do not rewrite earlier units.

CONTEXTS, DISCOURSE AND CHANGE
Contexts encode reported, believed, hypothetical, desired, promised, questioned,
uncertain or negated content. A context has optional holder and attribution_event,
parent context keys, and evidence. Events, discourse relations, identity links and
state updates can reference several contexts. An empty context list means the
narrator's unqualified discourse level, not independently established world truth.
Use nested context parents to preserve attribution; an attribution event itself
belongs to the surrounding context, not automatically its own reported content.
Event polarity records local propositional negation. Use a negated context only
when negation scopes over content beyond that local proposition; avoid double counting.

Relations must connect supported events, including prior events. Temporal order,
causation, contrast, elaboration, etc. need evidence; sentence order alone does
not prove event order or causality. Distinguish explicit, inferred and unresolved.
Relations inside a hypothetical/reported timeline retain those contexts.
Identity links express same/different/possible identity discovered NOW; belief in
identity is contextualized. Existing historical IDs are never retroactively merged.
Entity updates record explicit state/property assertions or retractions with
their scope. Do not promote a wish, quotation or hypothetical property to fact.
When a semantic choice remains unresolved, record that uncertainty once, without
requesting a debate or proposing an unsupported confident answer.
